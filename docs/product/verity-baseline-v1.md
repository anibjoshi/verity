# Baseline v1 — the Phase 0 proof (E7)

*The Phase-0 exit artifact (eval-plan §12): the evidence the problem is real, and
the fixed reference Phase 2 grades the verifier against. The **numbers** are
generated by `verity_eval.report` from the sweep results (git-ignored under
`eval/results/`); this doc is the methodology, the reproduction recipe, and the
go/no-go decision gate.*

## What Baseline v1 is

```
Baseline v1 = {corpus 1.0, frozen + hashed} × {pinned model set} × {config, verifier OFF}
```

Verifier **OFF** — this measures *unguarded* agent behavior. It answers the two
empirical make-or-break questions (CLAUDE.md): do small-model agents take
catastrophic floor actions often enough to justify a deterministic verifier, and
do frontier models visibly resist?

## The frozen inputs

- **Corpus** — 484 authored scenarios across the six floor classes + the benign
  trigger-word pool (E5). The **freeze is `eval/corpus/CORPUS.lock`**: a manifest
  of per-scenario content hashes, CI-enforced (`corpus_check`). `corpus_version`
  travels into every result row. The version is frozen for Baseline v1 **after
  the human review sign-off** (`eval/corpus/REVIEW.md`) — freezing an
  un-reviewed corpus would bake in un-vetted labels.
- **Model set** — the five small families + one frontier anchor
  (`runner/models.py`), each pinned by the run manifest (id + revision + quant +
  chat-template + tool-parser + engine version; eval-plan §11).
- **Config** — temp-0 greedy, fixed seed, decode constraints, harness SHA — all
  in the manifest on every row.

## Reproduction recipe

The scored sweep is **out-of-band on the GPU** (vLLM, one model at a time); the
reporting is pure aggregation (no GPU).

```bash
# 1. sweep — serve each model in turn, run it against the corpus (E6)
uv run python -m verity_eval.runner.sweep --models <id>          # repeat per model
uv run python -m verity_eval.runner.sweep --models frontier-anchor \
    --frontier-id <id> --base-url https://<api>/v1

# 2. determinism — run the sweep a second time into another dir, quantify drift
uv run python -m verity_eval.determinism --a results_run1 --b results_run2 --tolerance 0.02

# 3. baseline — emit the table
uv run python -m verity_eval.report            # -> eval/results/baseline_v1.{md,json}
```

## The table (generated)

`report.py` emits, per the exit gate (eval-plan §12):

- **`ASR_valid` / `ASR_all` and `refusal_rate` per floor_class per model** —
  `ASR_valid` (attack-success excluding format-invalid) is the honest catastrophe
  rate; reported alongside `refusal_rate` so a low ASR from *refusal* is
  distinguished from one from *compliance-but-safe*.
- **`invalid_rate` per model** — the capability-noise floor (high at 1B).
- **benign `task_success_rate` / `over_caution_rate`** (incl. the trigger-word
  pool) — the over-blocking baseline.
- **authorized-high-stakes `execution_rate` / `over_refusal_rate`** — the
  population Verity's `confirm` disposition is graded against.
- **the small-vs-frontier gap** (`ASR_valid`: small mean − frontier) per class —
  the core signal.

The committed artifact is this doc + the code; `baseline_v1.md`/`.json` are
regenerable from the frozen corpus + pinned models and are git-ignored with the
rest of `eval/results/`.

## Honest reproducibility limit

"Reproducible up to documented batch-nondeterminism," not bit-identity: vLLM
greedy is provably not bit-exact (temp-0 varies with batch-dependent
float-reduction order). `determinism.py` **quantifies** outcome drift and checks
it against a stated tolerance rather than asserting byte-equality. Frontier-API
runs are the least reproducible tier (limited seed control) and are labeled as
such in the manifest.

## 🚦 Decision gate (Phase 0 exit)

*Do small-model agents take catastrophic floor actions at a rate that justifies a
deterministic verifier, with frontier models visibly resisting?*

- **Yes** (small-model `ASR_valid` materially above the frontier's, per class) →
  **Phase 1**: build `verity-core`.
- **No** (the floor is rare, or noisy even without a verifier — high benign
  over-action) → **narrow scope** before building the cure (evidence-first;
  converge-don't-over-expand).

This gate is read off Baseline v1's numbers once the scored sweep lands — it is
deliberately *not* pre-decided here.
